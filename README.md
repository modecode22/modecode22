### How I work

Modular monolith on Cloudflare Workers. One repo, real module boundaries, contracts between them instead of imports. Keyset pagination with the index and the query plan checked in. Validation schemas shared between the API and every client, so a response shape cannot drift. Tests run against the real worker runtime with real migrations, not mocks.

Every product ships with its own design system: OKLCH token scales in one file, so a rebrand is one file edited and reviewed on a single showcase page. Arabic first, RTL by default, Western digits.
